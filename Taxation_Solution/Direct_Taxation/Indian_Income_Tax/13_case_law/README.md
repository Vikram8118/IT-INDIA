# Case law

Policy: under the current source policy, judgments are not fetched from the internet. Case law enters this folder only when the owner supplies it. Each file goes in USER_SUPPLIED/ with a note of where it came from.

Each case needs a register entry (case_id, citation, provision_ids_discussed, holding_summary approved by the owner, status such as binding, persuasive, overruled or under_appeal) before it is cited in any output.

Where a provision has an ambiguity_flag, the related case law should be added here and linked to that provision.
