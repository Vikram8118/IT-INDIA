# Repository layout

Taxation_Solution/Direct_Taxation/Indian_Income_Tax/ is the root of the India income tax knowledge base.
Paths inside this repository are relative to that folder unless stated otherwise.

- raw/: original files as downloaded, read-only, with MANIFEST.csv (SHA-256).
- proposed/: converted markdown awaiting review.
- live/: approved content only (moved here by pull request).
- 00_governance to 13_case_law: working folders as described in README.md.

Future countries sit beside Indian_Income_Tax under Direct_Taxation, with the same layout.
